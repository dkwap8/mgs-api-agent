# MGS API Modern UI Update

The full Vue application now uses one consistent modern fintech design system across public authentication, merchant, and administrator interfaces.

## Updated surfaces
- Shared merchant and administrator layouts
- Login, registration, password recovery, and public home screens
- Merchant dashboard, analytics, wallet, customers, transactions, virtual accounts, payouts, API keys, webhooks, documentation, support, settings, and business activation
- Administrator dashboard, business activations, merchants, customers, transactions, providers, payouts, reports, support tickets, notifications, activity logs, and settings

## Design system changes
- Unified indigo fintech brand palette
- Slate-based light and dark themes
- Improved typography, spacing, radii, shadows, focus states, tables, cards, forms, and page transitions
- Responsive navigation and content surfaces retained

## Validation
`npm run build` completed successfully with Vite 8.
